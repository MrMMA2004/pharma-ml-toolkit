1. Purpose and Method
This document is the complete, verified registry of every GitHub repository link provided by the project owner
across the PharmaML Toolkit sessions. It consolidates the thirty-three repositories named in the link-giving
instructions, plus the project's own private backup repository that was established during the MASTER_PROMPT
audit of 4-5 November 2026. Every entry carries the canonical URL exactly as it resolves today, the toolkit
version and date in which the link was given, the module or engine that the repository fed, and its current status
within the project.
The register was reconstructed from the project's own audited records rather than from memory. The primary
sources are the per-round instruction quotes preserved verbatim in the toolkit CHANGELOG, the round entries of
the worklog, the round-187 six-repository review document, and the MASTER_PROMPT audit traceability
matrix. Where a repository was named in more than one instruction - captum, shap and rdkit each appear in two
absorption rounds - the register lists it once and cross-references every round in which it was given. No repository
was added on inference alone: an entry exists only where a recorded instruction, review document, or audit row
names it.
Every URL in this document was re-validated against the GitHub REST API on 5 November 2026. All thirty-four
entries returned HTTP 200. One redirect was resolved: pytorch/captum now resolves to meta-pytorch/captum,
which matches the verification note already recorded in the v1.2.105 changelog. The three repositories whose
records carry a name without a canonical owner - torchlens, alibi and Quantus - were resolved through repository
search and verified before inclusion. Live star counts are quoted throughout as evidence of liveness at verification
time, and the private backup repository was checked with an authenticated call.

6. The Project Backup Repository
During the MASTER_PROMPT audit the project itself gained a GitHub presence: a private backup repository
holding the full history of the workspace - the Next.js explorer application, the complete pharma-ml-toolkit
source tree, tests, notebooks, release archives and the audit documents. It was established with a fine-grained
personal access token that never enters the repository, its URLs or its logs, and every milestone of the audit was
pushed to it as it happened.
The repository has since been exercised for real. A sixth environment rollback reset the local workspace to a
day-old state, destroying the virtual environment, the credential files and the scheduler state - and the backup
restored all of it: the remote history was fetched, the local branch fast-forwarded back to the shipped v1.2.107
tree byte-for-byte, the dependency stack re-pinned, and the recovery verified with green test chunks before the
recovery record itself was pushed. The registry lists it as entry 34; its URL is private and authenticated, but it is as
much a part of the project's GitHub footprint as every repository the owner provided.
MrMMA2004/pharma-ml-toolkit
https://github.com/MrMMA2004/pharma-ml-toolkit
