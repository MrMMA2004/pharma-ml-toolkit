Full Python Backend Integration via FastAPI and WebSocket,

## 0. The environment boundary (read this first)

The development container is **Linux-only**. Consequences, stated
once and referenced everywhere below:

| part10 deliverable | Linux-container status |
|---|---|
| C# WinUI 3 / XAML / MVVM frontend **build & execution** | **BLOCKED** — WinUI 3 + Windows App SDK compile and run on Windows 10/11 only; no Windows host exists here. |
| FastAPI backend integration layer (Phase Six) | **REAL** — fully implemented and tested here. |
| Backend process lifecycle + startup handshake (Phase Seven) | **REAL** (backend side) — port-0 loopback bind, structured handshake, graceful shutdown, all tested. The *WinUI-side* supervisor (job objects, restart policy) is BLOCKED with the frontend. |
| Background Job Architecture (Phase Nine) | **REAL** — state machine, cooperative cancellation, progress events, tested. |
| PySide6 retirement (Phase Sixteen) | **BLOCKED** — the prompt's own rule #9: retire only after the new GUI passes complete functionality-parity; the new GUI cannot be built or tested here. PySide6 **stays** production. |
| Offline Windows EXE installer (Phases Eighteen-Twenty) | **BLOCKED** — same boundary as part9's §14 (a Windows host; see `packaging/windows/BUILD_REPORT.md`). |

Nothing on this page weakens a non-negotiable: no "scaffolded as
done", no cosmetic screenshot passed off as parity.

## 2. Phase Six/Seven/Nine — the opening implementation (this round)

All in `src/pharmaml/api/` (new package), tested by
`tests/api/test_backend_service.py` (42 tests, all green):

| Module | Implements | Test classes |
|---|---|---|
| `security.py` | session token (`secrets.token_urlsafe(32)`, memory-only, constant-time verify), loopback Host/Origin guard, Bearer + X-Session-Token | TestSessionSecurity (3), TestLoopbackGuard (7) |
| `events.py` | typed `EventEnvelope` (pydantic — the single wire DTO), 20-event vocabulary, per-bus monotonic sequencing, replay-since duplicate protection, bounded-queue backpressure with `bus.overflow` notices, thread-to-loop-safe publication | TestEventBus (5) |
| `jobs.py` | JobManager: full state machine (QUEUED→RUNNING→COMPLETED/FAILED, CANCELLATION_REQUESTED→CANCELLED), real cooperative cancellation (the RUNNING-path flag-set bug was caught by the suite and fixed), expensive-slot semaphore (no CPU oversubscription), graceful shutdown drain | TestJobManager (7) |
| `routes/events.py` | `/api/v1/events` WS: token handshake, hello+replay, heartbeats, ping/pong, REST-stays-authoritative | TestWebSocketEvents (3) |
| `routes/jobs.py` | submit/poll/result/cancel REST (the authoritative status path) | TestJobRoutes (4) |
| `routes/chemistry.py` | descriptors + fingerprints over the REAL backend functions — sync and job modes; strict-int validation (radius/n_bits bools → 422, per the backend's own rule) | TestChemistryRoutes (7) |
| `routes/health.py` | `/api/v1/health` — liveness + identity + scientific-core probe | TestHealth (2) |
| `routes/capabilities.py` | registry projection (62 rows) | TestCapabilities (3) |
| `server.py` | the controlled port-0 loopback bind (socket owned by us, handed to uvicorn by fd — no check-then-bind race), the single `PHARMAML-READY {port, token, pid, version}` stdout handshake, graceful SIGTERM shutdown | TestStartupHandshake (3, incl. the real serve with live HTTP probe) |

The OpenAPI contract is served at `/api/openapi.json` (docs/redoc
DISABLED per §9.4) — the C# client is generated from it (NSwag)
when a Windows host exists; one DTO definition, never two.
